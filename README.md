# Diabetes Prediction using ANN

## Project Overview
This project predicts whether a person is likely to have diabetes using an Artificial Neural Network (ANN).

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow / Keras
- Streamlit

## Dataset
Pima Indians Diabetes Dataset

## Features
- Pregnancies
- Glucose
- BloodPressure
- SkinThickness
- Insulin
- BMI
- DiabetesPedigreeFunction
- Age

## Target
- Outcome

## Model
Artificial Neural Network (ANN)

## Deployment
The trained model is deployed using Streamlit.
